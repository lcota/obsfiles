# Objective
SPP for Credit Trading is the Strategic Project Push plan which outlines a 3 year project timeline over which a global overhaul of credit trading capability is meant to take place. This outlines a budget, expected deliverables by team using a roadmap, and sets priorities for achieving the objectives for each region set forth in the SPP.
